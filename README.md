# Loan Approval Predictive Machine Learning Model

The following project leverages machine learning models to classify a person's loan approval eligibility (Approved or Not Approved) for a bank loan. Three classifiers (Logistic Regression, Naive Bayes, and Random Forest) were used on a dataset containing over 50,000 customers. Ultimately, the Random Forest was identified as the best performing model, with metrics that aligned closest to the target criteria, however the overall ability of the model was mediocre and should not be deemed as suitable for business use. 

For approved applicants, two Decision Tree Regression Models were built to estimate the maximum borrowing amount that can be offered to them. The strongest of the decision tree was pruned to obtain the prediction.
